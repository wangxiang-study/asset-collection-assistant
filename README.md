# 持物 · 录屏对照版（V3.4）

在线使用：https://wangxiang-study.github.io/asset-collection-assistant/

这是面向手机和桌面浏览器的离线优先网页应用。首次联网打开后可安装到主屏幕并缓存离线资源。数据默认保存在当前设备当前浏览器，可通过应用内 JSON 备份在设备间迁移。

## V3.4
- 资产、投资、虚拟物品的分类和自定义状态分别管理。
- 分类可新增、重命名、删除和排序；单件物品最多选择 3 个同类型分类。
- 购买渠道可在设置或新增物品时管理。
- 图标库显示具体中文名称，并支持按名称搜索和上传照片。
- 投资分类展示贵金属克重/价格、股票与基金持有量、存款信息；虚拟分类区分订阅、储值卡、礼品卡、游戏充值、数字藏品等页面。

## 使用
- iPhone / iPad：Safari 打开上方链接 → 分享 → 添加到主屏幕。
- Android：Chrome 打开上方链接 → 菜单 → 安装应用或添加到主屏幕。
- 离线使用前先联网打开一次。不同浏览器/设备数据不自动同步，请在“我的 → 数据备份”导出 JSON，再在另一设备导入。

基于 ItemMemo-APP 开源项目扩展，详见页面关于与开源说明及随附许可证。
