# 持物 · 录屏对照版（V3.6）

在线使用：https://wangxiang-study.github.io/asset-collection-assistant/

面向手机和桌面浏览器的离线优先网页应用。首次联网打开后可安装到主屏幕并缓存离线资源。数据保存在当前设备的当前浏览器，可通过 JSON 备份迁移。

## 版本更新

- **V3.6（2026-10-02）**：修复 iPhone Safari 上弹层输入框不能正常唤起键盘的问题；移除弹层渲染后的脚本自动聚焦，统一优化名称、分类、状态、渠道、支付方式等文本输入框的 iOS 可编辑性与字号；新增储值卡、会员卡、会员券、会员、优惠券、礼品卡图标组。V3.5 页面已归档于 `versions/chiwu-v3.5.html`。
- **V3.5（2026-10-02）**：把购买渠道与支付方式拆为两个独立字段；购买渠道默认有官网、京东、淘宝、线下等选项，支付方式默认有 Apple、支付宝、微信支付、信用卡、PayPal 等选项；两套选项可分别新增、删除和管理；详情页分别显示渠道和支付方式。旧版数据中的渠道值保留。
- **V3.4（2026-10-02）**：资产、投资、虚拟分类与自定义状态独立管理；分类可新增、重命名、删除、排序，单件最多选 3 个同类型分类；图标显示具体中文名称；投资、虚拟物品分类联动专属信息页面。

## 安装与使用

- iPhone / iPad：Safari 打开链接 → 分享 → 添加到主屏幕。
- Android：Chrome 打开链接 → 菜单 → 安装应用或添加到主屏幕。
- 离线使用前先联网打开一次。不同设备的数据不会自动同步，请在“我的 → 数据备份”导出 JSON，再在另一设备导入。

基于 ItemMemo-APP 开源项目扩展，详见应用内开源说明及随附许可证。
