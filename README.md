# 物记

一个轻盈的个人持物管理应用，支持添加到手机主屏幕与离线使用。

## 使用

通过 GitHub Pages 访问。iPhone/iPad 在 Safari 分享菜单选择「添加到主屏幕」；Android 在 Chrome 菜单选择「安装应用」或「添加到主屏幕」。

## 数据

资产和图片仅保存在当前浏览器的本地存储，不上传到 GitHub，不提供跨设备同步。请在「我的」中定期导出 JSON 备份。旧的本地 HTML 数据需要先导出再导入网站。

## 功能

资产概览、分类、搜索排序、在用/心愿/已出状态、图片、编辑、估值与日成本、统计、JSON 备份。

## 更新

GitHub Pages 从 main 分支根目录发布；更新应用时需同时调整 sw.js 的缓存版本。
