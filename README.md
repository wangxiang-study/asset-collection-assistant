# 持物 V3.3 · 多设备浏览器版

**直接打开应用：** https://wangxiang-study.github.io/asset-collection-assistant/

这是基于 GitHub Pages 的可安装网页应用。请在手机浏览器打开上面的链接，然后添加到主屏幕：

- **iPhone / iPad：** 使用 Safari 打开 → 分享 →「添加到主屏幕」
- **Android：** 使用 Chrome 打开 → 菜单 →「安装应用」或「添加到主屏幕」
- **电脑：** 使用 Chrome / Edge 打开，可从地址栏安装图标或浏览器菜单安装

首次联网打开并缓存后支持离线使用。物品数据保存在**当前设备的浏览器本地**，不会自动跨设备同步；如需换设备，请在「我的 → 数据备份」导出 JSON，再在另一台设备导入。

## 功能

资产 / 投资 / 虚拟分类联动、分类专属字段、自定义状态、物品图标与照片、成本模式与目标、保修与到期提醒、退役与售出、储值卡充值消费流水、维护 / 配件 / 使用记录、统计图表、JSON 备份恢复、CSV 导出。

## 源码

`source/` 保留可编辑源码与构建脚本。网页缓存范围限于当前仓库，不与其他应用共用缓存。
